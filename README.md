## 🚀 Things I've Built

### 🔐 PassMimi

**Privacy-first offline password strength & breach analysis.**

PassMimi is an open-source password security analyzer for Windows and Linux designed to evaluate passwords **without sending them to a remote server**.

It combines password analysis with datasets such as **RockYou, SecLists, and Weakpass** to provide breach detection, estimated cracking times, and actionable security feedback.

**Focus:** Cybersecurity · Privacy · Password Security · Python

[Explore PassMimi →](https://github.com/faizanaauf/PassMimi)

---

### ⚡ SaveMimi

**A modern Windows download manager built around adaptive download acceleration.**

SaveMimi uses **MiMiFlow**, an adaptive download approach designed around dynamic connections, reliable resume behavior, and efficient downloading.

The goal is straightforward:

**Make downloading faster without making the experience complicated.**

**Focus:** Download Management · Networking · Performance · Windows

[Explore SaveMimi →](https://github.com/faizanaauf/SaveMimi)

---

### 📡 LanMimi

**Frictionless local file transfer from a laptop to Android.**

LanMimi transfers files over the local network through the phone's browser — meaning the receiving device doesn't need another dedicated mobile application.

No cloud upload.

No messaging yourself a file.

No unnecessary compression.

Just devices communicating directly over your LAN.

**Focus:** Local Networking · File Transfer · Browser-based Tools · Performance

[Explore LanMimi →](https://github.com/faizanaauf/LanMimi)

## 🧪 How I Think About Building
