## About Muhammad Faizan

Muhammad Faizan is a developer, entrepreneur, and researcher focused on building software that combines technical rigor with practical utility. His work spans **artificial intelligence, software engineering, privacy, cybersecurity, networking, automation, and human-computer interaction**.

I am interested in both sides of the system: the mechanics of the machine and the psychology of the humans using it. Many software problems are not purely technical; they stem from cognitive friction, misaligned incentives, weak defaults, or unnecessary complexity. My work focuses on removing friction, protecting user privacy, and turning overlooked "what if?" questions into reliable, functioning software.

## Featured Projects

### [PassMimi](https://github.com/faizanaauf/PassMimi)
**Privacy-first offline password strength analyzer and breach detection tool.**
- **Problem Solved:** Most password analyzers either check arbitrary character rules or send credentials to remote cloud APIs, creating potential attack surfaces.
- **Solution:** PassMimi evaluates passwords completely offline using real-world research datasets (**RockYou, SecLists, Weakpass**). It estimates brute-force crack times, inspects character diversity, and provides actionable recommendations with zero telemetry and zero external network calls.
- **Technologies & Domain:** Python, Flask, PyWebView, HTML/CSS/JavaScript • *Cybersecurity & Privacy*

### [SaveMimi](https://github.com/faizanaauf/SaveMimi)
**Modern Windows download manager powered by adaptive connection acceleration.**
- **Problem Solved:** Traditional downloaders either rely on static connection allocations that fail to adapt to fluctuating network speeds or leave cluttered metadata debris across user folders when connections drop.
- **Solution:** Built around **MiMiFlow**, an adaptive download engine that continuously evaluates throughput, latency, and server responsiveness to dynamically manage parallel connection streams. Includes seamless pause/resume, network dropout recovery, and an isolated state architecture that keeps target download folders completely clean.
- **Technologies & Domain:** Windows Desktop Tooling, Adaptive Networking, Multi-Threaded Streaming • *Systems & Networking*

### [LanMimi](https://github.com/faizanaauf/LanMimi)
**Frictionless, app-less local network file transfer utility from laptop to Android.**
- **Problem Solved:** Moving large files across local devices typically requires third-party cloud uploads, messaging apps, account logins, or installing dedicated apps on every receiving device.
- **Solution:** LanMimi streams raw binary files directly over the local Wi-Fi router using an app-less mobile browser interface. Files transfer with zero compression and zero third-party exposure. Built with strict 64KB memory chunk streaming to ensure minimal RAM usage even with massive files.
- **Technologies & Domain:** Python Standard Library, HTTP Socket Streaming, Responsive Browser UI • *Local Networking & Systems*

### [SheharSuno AI](https://github.com/faizanaauf/sheharsuno-ai)
**Civic-tech AI platform translating natural citizen feedback into action-ready municipal complaints.**
- **Problem Solved:** Citizens in Pakistan often struggle to report municipal failures because complex bureaucratic jargon and confusing agency jurisdictions prevent complaints from reaching the correct department.
- **Solution:** SheharSuno allows citizens to report civic issues in everyday language (voice or text in Urdu, Roman Urdu, or English). AI structures the input into formal terminology, estimates severity, and generates an official, bilingual complaint draft routed directly to the responsible civic agency (such as WASA, LWMC, TEPA, or LESCO).
- **Technologies & Domain:** Next.js, React, TypeScript, Tailwind CSS, Leaflet, Civic AI • *Applied AI & Civic Tech*

### [Funternet Arcade](https://github.com/faizanaauf/funternet)
**Interactive web engine turning dense legal text and complex documentation into playable retro arcade games.**
- **Problem Solved:** Critical information—such as 40-page Terms & Conditions agreements, technical specifications, and privacy disclosures—is routinely ignored by 99% of internet users due to sheer cognitive fatigue.
- **Solution:** Funternet uses the Google Gemini API (`gemini-3.8-flash`) and procedural game mechanics to convert arbitrary dense text into real-time interactive challenges, including boss battles (e.g., the "Terms & Conditions Demon"), trivia gauntlets, and escape rooms with custom Web Audio sound synthesis.
- **Technologies & Domain:** TypeScript, Next.js, React 19, Google Gemini API, Tailwind CSS, Web Audio API • *Generative AI & Gamification*

## Areas I Explore

My research and development focus sits at the intersection of technical systems and human behavior:

- **Applied AI & Intelligent Automation:** Building practical AI tools that solve concrete friction points rather than chasing novelty. Exploring generative interfaces, agentic pipelines, and natural language translation of real-world problems.
- **Privacy & Cybersecurity Engineering:** Creating local-first, zero-telemetry software where sensitive computation (such as credential evaluation) stays strictly on the user's hardware.
- **Systems & Network Efficiency:** Designing low-overhead network tooling, adaptive parallel transfers, and zero-compression local protocols that eliminate unnecessary intermediary cloud dependencies.
- **Psychology & Human-Computer Interaction:** Studying user attention, cognitive load, default-effect biases, and why humans adopt or resist digital tools.
- **Entrepreneurship & Product Architecture:** Identifying overlooked technical friction, testing assumptions with functional prototypes, and shipping sustainable, self-contained software.

## Building Philosophy

```python
while curious:
    problem = observe_friction()

    if problem.is_genuine():
        research(problem)
        prototype(problem)
        test_assumptions()

        if prototype.delivers_utility():
            build_it_properly()
```

- **Question defaults:** Most software patterns exist out of convention rather than necessity. Asking *"Why does everyone do it this way?"* often reveals opportunities for simpler, faster alternatives.
- **Value omission over complexity:** Not every problem needs a cloud backend, another database layer, or an AI model. Sometimes the most impactful engineering decision is removing unnecessary steps.
- **Respect user agency:** Systems should work for their users, not against them. Software should preserve privacy by default, operate transparently, and minimize unneeded cognitive load.
